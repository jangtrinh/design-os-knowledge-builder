# Art Direction — Isometric Technical Illustration (Assembled States Only)

> Standing visual specification for all architectural assets, documentation diagrams, and technical figures in `design-os-knowledge-builder`.  
> Adopted directly from the `jang-personal-site` technical illustration design system.

---

## 📐 The Core Invariants

| Invariant | Value | Rationale |
|-----------|-------|-----------|
| **Projection** | 2:1 isometric, axonometric | No perspective convergence; preserves geometric parallelism. |
| **Line Weight** | Uniform hairline | Clean, precise, blueprint-grade aesthetic. |
| **Line Colour** | Near-black `#202020` | High contrast on pure white without harsh clipping. |
| **Field** | Flat pure white `#ffffff` | Seamless integration into light mode README and documentation. |
| **Grid** | Faint isometric `#d0d0d0`–`#e4e4e4` | Structural reference fading softly toward canvas borders. |
| **Palette** | Pure greyscale | Zero chroma (white, light grey, mid grey, solid black). No color distractions. |
| **Typography** | **Zero in image pixels** | All labels, titles, and explanations must be DOM/Markdown text. Text in pixels cannot be searched, audited, or localized. |
| **State** | **Fully assembled / seated only** | **No exploded views.** All moving parts, trays, and cutting heads are seated down on their alignment pins and registration bases. |
